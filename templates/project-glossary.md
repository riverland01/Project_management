## Dictionary Rules

- Include only definitions, acronym expansions, aliases, and stable usage clarifications or definition sources.
- Exclude progress, completion, assignments, due dates, blockers, risks, approvals, dependency state, next actions, and decision history; route these to status, task, dependency, or log files.
- Update this dictionary only when terminology is introduced, clarified, or redefined. `Last updated:` tracks dictionary maintenance, not project status.
- Use the root `glossary.md` for workspace-wide terminology.
- Keep definitions concise; source material, meetings, tasks, and decisions may introduce terms, but their operational updates belong outside this dictionary.
