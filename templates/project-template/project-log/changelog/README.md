# Changelog

Store dated records of meaningful project changes here.

Recent Changes in `STATUS.md` and Done Recently in `TASKS.md` each retain at most 5 entries. Before trimming, preserve the older details, outcomes, dates, and source tags here or in an existing indexed evidence note; reuse sufficient records rather than duplicating them. Keep a history link in the summary. Claim tags follow `maintenance/claim-sources.md`.

For assignment changes, use `templates/ingestion/role-change-record.md` and name records `YYYY-MM-DD-role-change-<person>.md` using the recorded date. Link them from the stakeholder register and relevant index; preserve effective dates separately and retain earlier records.
