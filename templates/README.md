# Templates

This folder contains reusable Markdown templates for the project management workspace.

Use these templates when creating new workspace-level files, new projects, or dependency tracking files. Keep copied templates concise and remove sections that do not apply.

## High-Priority Templates

- `workspace-README.md`
- `workspace-STATUS.md`
- `workspace-INDEX.md`
- `project-README.md`
- `project-STATUS.md`
- `project-TASKS.md`
- `project-INDEX.md`
- `project-dependencies.md`
- `dependencies-active.md`
- `dependencies-dependency-map.md`

## Project Scaffold

- `project-template/` - copy this folder to `projects/<project-name>/` when starting a new project.
