## Findings

### F01: Minimum-overlay guidance omits the project glossary

- Check: J06. Severity: Warning. Disposition: Design. Open.
- Evidence: root `README.md`, Operating Notes, lists `README.md`, `STATUS.md`, `TASKS.md`, `INDEX.md`, and `dependencies.md` as the minimum overlay. `AGENTS.md` and `projects/README.md` also include `glossary.md`.
- Impact: a person following only the README may omit terminology needed by later readers.
- Recommended correction: add `glossary.md` to that README bullet, keeping `AGENTS.md` as the authority. No project state needs to be invented or changed.

### F02: The scaffold index presents optional files as if they already exist

- Check: J08. Severity: Warning. Disposition: Design. Open.
- Evidence: both `templates/project-INDEX.md` and `templates/project-template/INDEX.md` list `planning/roadmap.md`, `planning/milestones.md`, `planning/risks.md`, `planning/open-questions.md`, and `docs/project-brief.md`. None of those five files exists in the scaffold folder being copied.
- Impact: an unchanged copied index can direct readers to missing files. These are backticked references in a template, not five confirmed broken links in a live project.
- Recommended correction: mark the entries as optional/not yet created, or instruct the creator to remove them until files exist. Keep both template copies aligned. Do not require every project to create unused documents.

### F03: Root current-state dates are old, but age alone does not show a false claim

- Check: S05 context observation. Severity: Info. Open observation, no defect confirmed.
- Evidence: root `STATUS.md` and other inspected current-state files are dated 2026-05-28, 159 days before this review. Their empty-workspace description agrees with the project inventory.
- Impact: the dates do not tell a future reader whether the workspace was reviewed recently. They do not establish a stale project claim.
- Recommendation: update a review date when a substantive review actually occurs, explaining its scope. Do not automatically refresh every date during lint or treat the empty workspace as an overdue project.
