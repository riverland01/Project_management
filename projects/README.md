# Projects

Project-specific folders live here.

## Adding A Project

1. Copy `templates/project-template/` into `projects/<project-name>/`.
2. Replace placeholders in the copied `README.md`, `STATUS.md`, `TASKS.md`, `INDEX.md`, `glossary.md`, and `dependencies.md`.
3. Initialize `docs/stakeholders.md` when tracking people and link shared organizational contacts when relevant. If omitting this optional register, remove its README/index links; do not invent assignments to populate it.
4. Update root `STATUS.md` and `INDEX.md`.
5. Add cross-project dependencies to `dependencies/active.md` when needed.

## Naming

- Use short, readable folder names.
- Prefer lowercase words separated by hyphens.
- Keep project-specific instructions inside the project folder.
